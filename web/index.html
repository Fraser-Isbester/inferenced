The intercept path

One request in. Full observability out.

Every inference call flows through five stages — the client never waits on any of them.

01
🛰️

Intercept

A local reverse proxy catches outbound LLM traffic — no per-user config.

02
🧭

Detect

Host-first, then heuristic matching resolves the Provider — Anthropic, OpenAI, more.

03
🔱

Tee

TeeReader + io.Pipe forks the stream: hot path to client, copy to the meter.

04
📊

Meter

An incremental stream parser counts tokens and prices them to USD as they fly by.

05
📡

Emit

A structured Event lands in a Sink — stdout today, control plane tomorrow.

Quickstart

From clone to metered in 30 seconds.

# build & run the gateway (stdlib Go, one binary) go run ./cmd/gateway --port=8766 # point any client at it — no code changes export ANTHROPIC_BASE_URL=http://127.0.0.1:8766 # use your tools exactly as before… claude # or the OpenAI SDK, curl, anything # …and watch the telemetry stream: [RESPONSE] <-- Complete | Status: 200 | Provider: anthropic | Model: claude-opus-4 | Tokens In: ~1204 | Out: ~318 | Approx Cost: $0.04127
  • 1
    Drop it in the path

    The gateway listens on localhost and forwards upstream over HTTPS. Existing tools just work.

  • 2
    It detects the provider

    Host-first resolution picks the right parser and pricing automatically.

  • 3
    The stream is tee'd

    Your tokens arrive block-by-block in real time while a copy is metered.

  • 4
    You get a structured event

    Provider, model, redacted auth, developer id, token counts, and cost — every call.
